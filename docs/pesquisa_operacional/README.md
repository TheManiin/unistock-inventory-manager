# Pesquisa Operacional - UniStock

Documentação referente à Disciplina 4 do Projeto GSC.

---

# Objetivo

Aplicar técnicas de Pesquisa Operacional no sistema UniStock para apoiar decisões estratégicas relacionadas à maximização de lucro, minimização de custos e análise de cenários.

---

# Conteúdo Desenvolvido

- Modelagem matemática de maximização de lucro
- Modelagem matemática de minimização de custos
- Resolução dos problemas utilizando Python
- Uso da biblioteca PuLP
- Definição de variáveis de decisão
- Definição de função objetivo
- Definição de restrições
- Análise de cenário What-If
- Análise crítica dos resultados

---

# Arquivos da Disciplina

- [Maximização de Lucro](./MAXIMIZACAO_LUCRO.md)
- [Minimização de Custos](./MINIMIZACAO_CUSTOS.md)

---

# Ferramentas Utilizadas

- Python
- Google Colab
- PuLP
- Programação Linear
- Modelagem Matemática

---

# Conclusão

A disciplina permitiu transformar problemas reais de decisão do UniStock em modelos matemáticos, utilizando algoritmos em Python para identificar escolhas mais eficientes, reduzir custos e apoiar a gestão do projeto com base em dados e restrições operacionais.
