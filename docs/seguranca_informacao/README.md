# Segurança da Informação - UniStock

Documentação referente à Disciplina 3 do Projeto GSC.

---

# Objetivo

Implementar práticas de Segurança da Informação no sistema UniStock, abordando:

- mapeamento de ameaças
- controle de acesso
- proteção de dados
- adequação à LGPD
- mitigação de vulnerabilidades

---

# Conteúdo Desenvolvido

- Matriz GUT de ameaças
- Políticas IAM
- Controle RBAC
- Segurança de autenticação
- Proteção contra SQL Injection
- Adequação à LGPD
- Análise crítica de vulnerabilidades

# Conclusão

A disciplina permitiu identificar vulnerabilidades reais do sistema UniStock e definir estratégias modernas de proteção de dados, autenticação segura e mitigação de riscos operacionais.
