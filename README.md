Sistema de gerenciamento de estoque desenvolvido para controle de produtos, movimentação de estoque e análise de vendas em lojas de sneakers.

---

# Sobre o Projeto

O UniStock é um sistema desenvolvido para auxiliar pequenas lojas no gerenciamento de estoque, permitindo:

- Cadastro de produtos
- Controle de entrada e saída
- Monitoramento de estoque
- Relatórios operacionais
- Análise de vendas
- Apoio à tomada de decisão

O projeto foi desenvolvido na disciplina de Gestão de Sistemas Computacionais utilizando conceitos de desenvolvimento de software, análise de dados e Pesquisa Operacional.

---

# Problema

Muitas pequenas lojas ainda utilizam planilhas ou métodos manuais para controlar estoque, o que pode causar:

- Erros operacionais
- Perda de produtos
- Falta de controle financeiro
- Dificuldade em análise de vendas
- Problemas de reposição de estoque

---

# Solução Proposta

O UniStock centraliza o controle operacional da loja em um único sistema.

O sistema permite:

- Cadastro de produtos
- Controle automatizado de estoque
- Registro de movimentações
- Relatórios operacionais
- Alertas de estoque baixo
- Organização de informações
- Simulação de cenários operacionais

---

# Pesquisa Operacional

O projeto também conta com modelos matemáticos desenvolvidos utilizando Programação Linear para:

## Maximização de Lucro
Modelo responsável por identificar a combinação ideal de projetos para maximizar o lucro da empresa.

## Minimização de Custos
Modelo responsável por reduzir custos operacionais mantendo restrições mínimas de funcionamento.

## Análise What-If
Simulação de cenários críticos considerando redução de recursos operacionais.
